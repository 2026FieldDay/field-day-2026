# 2026 Combined Popcorn Seed Companies Field Day

Static, responsive website prepared for GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named `field-day-2026`.
2. Upload **the contents of this folder** so `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.

## Update content

- Main page content: `index.html`
- Styling: `styles.css`
- Countdown and mobile menu: `script.js`
- Images, logos and maps: `assets/`

## Important review items

Before public launch, confirm:
